# Homepage visual QA

- Route: `/`
- Primary reference: `references/homepage-mobile.png` (798 × 1972).
- Stack: dependency-free semantic HTML and CSS, served by a small Node.js static server.
- Asset integration: the four supplied nail images are presented in filename order across the `Our work` gallery. `public/images/Nail art example 4.png` now fills the previously missing fourth position. The three existing nail photographs and `public/icons/logo.png` remain in use.
- Interior integration: the supplied original `public/images/salon interior photo.jpg` production asset is placed in the right-hand side of the About Lark panel. Its responsive arched frame, fixed media height, `object-fit: cover`, and focal position reproduce the reference image's visual role without modifying the binary asset.
- Target review viewports: 798 × 1972 (reference), 390 × 844, 320 × 800, and 1024 × 900.
- Static responsive review: the four-column gallery retains the reference's narrow portrait tiles at desktop, typical mobile, and compact mobile widths. The interior frame scales from 290 px to 215 px while the existing two-column About layout and section height are preserved. Image paths, alternative text, intrinsic interior dimensions, lazy loading, focus styles, reduced motion, and horizontal-overflow-sensitive grid sizing were reviewed.
- Automated checks: `npm run check`, `npm run build`, direct HTTP requests to the page and both newly integrated assets, `git diff --check`, and a source-level asset mapping check.
- Screenshot limitation: deterministic browser capture remains unavailable in this container. No browser binary is installed, and the required Playwright package download is rejected by the package registry with HTTP 403. The screenshot/overlay comparison and browser-driven keyboard, zoom, and accessibility inspection therefore remain to be completed when a browser is available.
- Remaining visual differences: the supplied salon photograph depicts a wider manicure station than the more tightly composed chair-and-shelf scene in the design reference, so the subject matter within the faithful arched crop cannot match pixel-for-pixel. The supplied nail photographs also differ in content and lighting from the conceptual photographs embedded in the reference; their order, tile proportions, spacing, radii, and crop treatment follow the reference while preserving the originals as required. Browser/font rasterization differences remain unmeasured because capture is unavailable.
